Extract verbatim supporting passages from each document that answer the question.

# What to extract
A "supporting passage" is the complete portion of the document a researcher
would highlight to justify the answer, including:

- The sentence(s) that directly address the question.
- Any preceding setup sentence(s) that introduce the topic, methodology,
  or figure being referenced (e.g. "The bar chart in Figure 4 illustrates…",
  "We conducted three experiments…").
- Any concluding interpretation sentence(s) that summarize implications
  (e.g. "This observation underscores…", "These results suggest…").
- Table captions when the table itself is relevant. Include the caption;
  you may also include the table rows if they fit in a single passage.

Prefer a single continuous paragraph over multiple fragments of the same
paragraph. Only split into multiple spans when relevant content is in
non-adjacent parts of the document.

# Rules
1. Use EXACT text from the document — no paraphrasing, no edits.
2. Preserve the original wording, capitalization, and punctuation.
3. If no passage in the document supports the answer, return an empty array.
4. Order spans within each document by relevance, most relevant first.

# Output format
Return JSON mapping document IDs to arrays:
{
  "doc_0": ["first supporting passage", "second supporting passage"],
  "doc_1": ["passage from doc 1"],
  "doc_2": []
}
